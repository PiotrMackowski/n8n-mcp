# n8n-MCP (Fork)

Personal fork of [czlonkowski/n8n-mcp](https://github.com/czlonkowski/n8n-mcp) — a Model Context Protocol server providing AI assistants with access to n8n node documentation, properties, and operations.

## Quick Start

```bash
npx n8n-mcp
```

## Configuration

See the [upstream repository](https://github.com/czlonkowski/n8n-mcp) for full documentation, Claude Desktop setup, Docker deployment, and available MCP tools.

## Development

```bash
npm install
npm run build
npm run rebuild
npm start
```

## Tests

```bash
npm test              # All tests
npm run test:unit     # Unit tests only
npm run test:integration  # Integration tests (some require N8N_API_URL/N8N_API_KEY)
```
